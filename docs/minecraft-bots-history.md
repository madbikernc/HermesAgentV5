# Minecraft Bots — Change History

**Version:** 1.6.0

Every changelog for the Minecraft bot fleet, extracted here so the documents themselves stay
lean. Rows are verbatim and append-only, in the order they were written. Nothing here is
current-state reference — for that see `../MINECRAFT_BOTS_DESIGN.md`.

Sources, and where each one's rows came from:

| Document | Rows | Covers |
|---|---|---|
| `MINECRAFT_BOTS_DESIGN.md` | 56 | Design, build, and every live incident 2026-09-06 → 2026-09-24 |
| `services/minecraft-bots/README.md` | 46 | Orchestrator implementation |
| `agents/minecraft-*/PROMPT.md` | 18 | The nine personas |

Everything else keeps its own table: the `infra/minecraft-bots*` recreate checklists and the
`tools/` scripts are short enough that splitting them would cost more than it saves, and the
scripts carry their changelog as a header comment rather than a table.

For the narrative behind any row: `git log -p -- <the file>`.
